## 비교 규칙

논문별 비교표는 한 편에 한 행을 쓴다. 로봇, 관측·데이터, 적용 조건, 제어 수준과 시간 범위를 함께 적는다. 평가에는 과제, 데이터 분할, 지표, 실기 여부와 반복 횟수를 기록하고 근거가 있는 절·표에 연결한다. `CURATION-SEED`는 정독 전 비교 가설이다.

| 비교 질문 | 함께 확인할 조건 |
|---|---|
| 행동 표현과 로봇 간 전이 | 좌표계·행동 단위·제어기·실제 물리 효과 |
| 관측과 제어의 시간 | 관측 시차·행동 큐·제어 주기·계산 예산 |
| 상태 추정과 기억 | 가시성·관측 비용·오래된 상태의 영향 |
| 접촉과 안전 | 부착·접촉 모드·그래프 또는 지도 오차·실행 가능한 대안 |
| 적응과 평가 | 데이터·상호작용 예산·독립 결과·실패와 reset 분모 |
