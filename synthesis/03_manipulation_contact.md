# Manipulation, Contact, Tactile, and Dexterity

## Scope

Grasping, contact-rich planning, force/tactile feedback, dexterous manipulation, deformables, tools, assembly를 하나의 physical interaction 축에서 비교한다.

## Reading Path

Contact mechanics/optimization → grasp generation → tactile dynamics and feedback → dexterous tracking → deformable/tool/assembly → force-aware VLA.

- Tactile/force 신호를 VLA의 낮은 control rate와 어떻게 결합할 것인가?

- Dexterous policy의 object/task generalization을 어떤 benchmark로 신뢰성 있게 평가할 것인가?
