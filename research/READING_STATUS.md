# 읽기 상태와 논문 노트

[현재 읽기 기록](./READING_STATUS.csv)에는 CORE·NEXT만 들어간다. [이전 기록](./READING_STATUS_HISTORY.csv)은 집중 읽기에서 빠진 논문의 원래 상태와 메모를 보관한다. 등급이 바뀌면 생성기가 `overview_path`로 기록을 옮기고, 다시 편입하면 복원한다.

## 상태와 근거

`status`는 사용자가 실제로 읽은 단계다. `evidence_level`은 사용한 근거의 범위다. 새 기록은 `UNREAD`로 시작한다. 근거는 노트에서 확인된 수준을 반영하고, 분류 근거만 있을 때는 `CURATION_ONLY`를 쓴다.

| 상태 | 필요한 근거 | 기록할 내용 |
|---|---|---|
| `UNREAD` | 최소 수준 없음 | 원문 감사나 자동 노트가 있어도 읽기 이력이 없으면 이 상태를 유지한다. |
| `SKIMMED` | `ABSTRACT_CHECKED` 이상 | 초록·주요 그림으로 파악한 문제와 다음 확인 사항을 적는다. |
| `READ` | `FULL_TEXT_CHECKED` 이상 | 아래 여섯 분석 필드와 본문 위치를 기록하고 같은 트랙의 비교표에 행을 추가한다. |
| `SYNTHESIZED` | `FULL_TEXT_CHECKED` 이상 | 직접 선행·후속과의 차이, 그 차이에서 검증할 질문을 비교표와 Open Questions에 남긴다. 이론 논문은 여기서 완료할 수 있다. |
| `REPRODUCED` | `EXPERIMENT_CHECKED` | 핵심 실험을 실행하고 조건·결과나 재현 경로를 `personal_notes`에 기록한다. |

`ABSTRACT_CHECKED`는 공식 초록·게재처·저자 프로젝트에서 직접 확인한 범위다. `FULL_TEXT_CHECKED`는 방법·실험·한계의 근거 위치, `EXPERIMENT_CHECKED`는 실행 조건과 실측 결과를 요구한다. 요약 몇 문장을 대조했다면 해당 문장에 쪽수·절을 붙여 감사 원장에 남긴다. [원문 감사](./SOURCE_AUDIT.md#요약기여-원문-대조)

## 입력 필드

`started_on`은 읽기 시작일, `completed_on`은 합성 또는 재현 완료일을 `YYYY-MM-DD`로 적는다. `SKIMMED`는 아래 중 문제·다음 행동 두 필드가 필요하다. 나머지 읽기 위치·서지 필드는 원장과 [읽기 계획](./READING_PLAN.md)에서 생성한다.

| 분석 필드 | 내용 |
|---|---|
| `problem_and_assumptions` | 해결할 문제와 핵심 가정 |
| `observation_state_action_control` | 관측·상태·행동 표현과 제어기 연결 |
| `embodiment_task_data_metrics` | 기체·과제·데이터·평가 지표 |
| `failure_modes` | 저자가 밝히거나 실험에서 관찰한 실패 조건 |
| `research_relevance` | 현재 연구에서 재사용·반박·확장할 지점 |
| `next_action` | 정독, 비교, 코드 확인, 재현 중 다음 행동 |

## 논문 노트의 공통 검토 기준

폴더마다 다음 다섯 파일을 둔다. 공식 제목·연도·발표 상태·분류·원문·코드·프로젝트·검토일은 개요에 모은다. 다른 네 노트에는 제목, 개요 상대 링크와 각 노트에서 확인한 근거 범위를 적는다.

| 노트 | 확인할 내용 |
|---|---|
| `01_overview.md` | 문제와 중요성, 기여 2–4개, 입력·상태·출력, 평가 범위와 읽는 이유를 적는다. |
| `02_problem.md` | 기존 병목과 바뀐 문제 설정, 상태·관측·결정·제약·종료의 정의를 확인한다. 저자의 가정과 독자가 제안하는 스트레스 테스트를 구별한다. |
| `03_method.md` | 새 구성요소와 기준선을 구별한다. 학습·배포 입력, 목적함수·제어 법칙, 파라미터 단위·초깃값, 좌표계·메모리·제어 주기·지연, 하위 제어기 명령을 확인한다. |
| `04_evaluation.md` | 로봇·시뮬레이터, 데이터의 학습·평가 역할과 분할, 기준선·절제 실험, 성공·충돌·시간 초과의 정의, 시행·시드·분모와 추정치의 불확실성을 표·그림에 연결한다. 관측·제어기·시연·연산 예산을 맞췄는지와 실패·일반화·재현 범위를 적는다. |
| `05_insights.md` | 원문이 지지하는 결론과 연구자의 해석을 나눈다. 취약한 가정, 직접 선행과의 차이, 반증할 수 있는 질문과 최소 비교를 적는다. |

초록만 확인했으면 그 범위를 표시하고, 깨진 PDF 발췌는 원문을 대조한 뒤 사용한다. 데이터셋 이름이 언급됐다는 이유로 평가에 사용했다고 기록하지 않는다. [분야별 합성](../synthesis/README.md#공통-비교-규약과-질문-분류)
