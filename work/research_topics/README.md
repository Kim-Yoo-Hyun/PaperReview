# 연구 주제

<a id="candidate-priority"></a>
<a id="masters-publication-comparison"></a>

현재 질문은 **같은 위 칸 수납 지시에서 서랍의 개방 폭이 보이는 시점에 따라 접근과 수납이 어떻게 달라지는가**이다. LIBERO 배치 2에서 앞 0.5초의 영상 교환은 자기 폭 대조와 첫 접촉이 모두 같았고, 뒤 0.5초의 교환은 120/128쌍에서 달라졌다. 다음 비교에서는 이 시간대 차이가 배치 3에서도 나타나는지 검사한다.
