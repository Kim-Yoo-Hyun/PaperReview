현재 검증하는 질문은 **같은 위 칸 수납 지시에서 다른 서랍의 개방 위치와 폭이 로봇 행동을 어떻게 바꾸는가**이다. 공개 LIBERO 초기 배치 2의 두 복귀 자세를 사용한다.

| 필요한 자료 | 문서 |
|---|---|
| 무엇을 측정했고 어디까지 해석할 수 있는가 | [서랍 위치 비교](./instruction_revision/내용/README.md#drawer-location) |
| 어떻게 출발 상태와 저장 명령을 재생하는가 | [로컬 Docker 재현](./instruction_revision/재현%20방법/README.md) |
| 다음에 고정하거나 바꿀 변수 | [다음 작업](../../TODO.md) |
| 이전 후보의 결과와 재개 조건 | [종료·보류 결과](./RESULTS.md) |

직전 실험에서 닫힌 장면의 성공 명령은 아래 칸을 열어도 32/32회 위 칸 수납을 달성했다. 후속 비교에서는 그릇과 접시의 위치를 고정한다. 제약 갱신기 학습은 보류 중이다.
