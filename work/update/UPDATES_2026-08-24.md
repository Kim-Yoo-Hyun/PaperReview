## Gap updates

상세 판정은 [RESEARCH_GAPS.md](../../research/RESEARCH_GAPS.md)에 반영했다.

- **G-01/G-05:** tactile/force feedback이 없다는 주장은 더 이상 유지하지 않는다. 남은 질문은 sensor mechanics·embodiment·contact regime가 달라질 때 calibration과 safety가 유지되는지다.
- **G-02:** failure recovery 자체는 FLARE와 FaultEval로 좁혀졌다. RP-2는 binary Retry/Reset·rollback을 재발명하지 않고, multi-option operational recoverability를 동일 time/action/risk budget과 oracle decomposition으로 비교한다.
- **G-04:** sparse memory retrieval은 최신 baseline으로 추가했다. 남은 공백은 stale-memory expiry, phase transition, active re-observation의 safety effect다.
- **G-10:** VLA-Arena의 stress dimensions를 반영했지만, 공통 event timestamp·recovery budget·post-recovery outcome은 별도 protocol이 필요하다.
- **G-13:** active attention/state가 직접 다뤄졌으므로, 연구 질문을 active perception의 존재 여부가 아니라 physical camera cost와 action-value stopping으로 한정했다.

## Reading and experiment consequence

1. 새 9편을 해당 CORE lineage 뒤에 읽는다. 특히 SAFE → FLARE/FaultEval/TD calibration → RP-2 순서를 유지한다.
2. Tabero/TactAlign은 AT-VLA·ForceVLA2 뒤에 읽어 force quality와 cross-sensor transfer를 비교한다.
3. Memory Retrieval/AVA-VLA는 MomaGraph·Spatial Memory·ActiveVLA 뒤에 읽어 memory update와 active observation을 분리한다.
4. VLA-Arena는 LIBERO/CALVIN/FurnitureBench의 event schema를 고정한 뒤 stress-suite로 사용한다.
5. 새 paper의 full-text 정독이 끝나기 전까지 `RESEARCH_GAPS.md`의 기존 `READING-SUPPORTED`를 새 paper 근거로 확대하지 않는다.
