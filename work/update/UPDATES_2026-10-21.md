# 2026-10-21 — C1 native probe 및 C2 후속 문헌·정적 감사

## 연구 판단

[10월 20일 후보 선별](./UPDATES_2026-10-20.md)에 이어 C1을 먼저 진행했다. [후속 검토](../research_candidates/2026-10-20_vla_rl/C1_REVIEW.md)에 ActiveAlign·EyeRobot 2.0·EgoReveal·PhysCaP의 관련 본문 확인과 기존 RESCUE의 평가 formulation 재대조를 반영했다. 최신 preprint의 venue는 미검증으로 유지한다.

넓은 active-perception RL 및 counterfactual evaluation을 새 기여에서 제외하고, 선택적 관측의 순이득으로 질문을 축소했다. 추가 근거 없이 C1을 본격 학습 주제로 채택하지 않는다. 다음 문헌 작업은 C2 직접 충돌 검토이며 C2의 우월성이 검증된 것은 아니다.

## 실행·정리

- [Native 결과](../experiments/vla_rl_active_handoff/RESULTS.md): 공개 SmolVLA strict load·실제 LIBERO 입력·finite action 243개를 확인했다. 첫 task는 900초 기준에 걸려 `budget_exhausted`, 실제 903.13초에 종료했다. 평균 inference 3.558초, process 최대 RSS 약 5.12 GiB다.
- 완결된 episode는 0개이며 두 번째 task는 미시작이다. 실패 성공률을 만들지 않았고 base competence·C1 효과·RL 필요성은 미확인으로 남겼다.
- 고정 config의 실행 길이 1을 유지했다. Checkpoint model card의 training/evaluation provenance 부족과 π0.5 평가 recipe를 전용할 수 없다는 제한을 기록했다.
- 실험·패키지·모델·simulator assets는 Docker 내부에만 두었다. 결과를 보존한 뒤 전용 container/image/volume 각 1개와 해당 build-cache 12개를 정리했다. 무관한 `minikube` volume은 보존했다.
- [Source audit](../research_candidates/2026-10-20_vla_rl/C1_SOURCE_AUDIT.json)는 17개 정적 파일, [runtime manifest](../experiments/vla_rl_active_handoff/runtime_manifest.json)는 실제 실행 image/source hash·종료 상태·정리 대상을 구분한다.
