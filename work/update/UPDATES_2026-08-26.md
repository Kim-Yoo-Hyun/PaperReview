# RP-2 Final Scope and Experiment Specification — 2026-08-26

## Final documentation pass

`research/projects/RP-2_FAILURE_RECOVERY.md`를 RP-2 실행 전 최종 문서 기준으로 보강했다.

- RP-2를 low-level torque/force controller가 아닌 frozen VLA 위의 high-level runtime recovery supervisor로 명시했다.
- detection·diagnosis·recovery decision을 분리하고, scalar alert가 action-conditioned recovery를 결정하지 못한다는 operational motivation과 crossing test를 추가했다.
- detector → belief/type → option-value → constrained selector → fixed controller의 정보 경계를 명시해 oracle leakage와 privileged replan 혼입을 막았다.
- `D0-native`, `D1-event`, `D2-option`, `D3-transfer`, optional `D4-physical` dataset layer와 provenance/hash/version 기록 규칙을 추가했다.
- B9 uniform feasible selector null baseline과 비교 질문별 사전 고정 pair를 추가했다.
- protocol validity metric(restore determinism, event completeness, onset consistency, option-sweep stability, adapter agreement)을 추가했다.
- optional real-robot `C3` gate와 physical metric을 별도 phase로 분리했다. simulator 결과만으로 physical safety를 주장하지 않는다.

이번 pass는 paper registry와 tier를 변경하지 않고 RP-2의 scope, motivation, method boundary, baseline, metric, dataset, real-robot extension을 정리한 것이다.

## Research-idea realignment from the updated gaps

`research/RESEARCH_IDEAS.md`를 같은 날짜의 gap closure audit에 맞춰 다시 정렬했다.

- 13개 gap을 12개의 독립 novelty claim으로 취급하지 않고 6개 research program의 decision experiment로 유지했다.
- RP-2의 중심 질문을 broad typed recovery에서 **same-onset counterfactual recovery arbitration**으로 축소했다.
- I-12를 공통 event·clone·budget protocol과 option-outcome table을 만드는 active infrastructure로, I-06을 I-02 결과가 지지될 때만 수행하는 optional policy-reuse 단계로 배치했다.
- I-02의 option library에 abort, retry, reobserve, state reset, subgoal rewind, task replan, human escalation을 명시하고, 동일 cloned onset·동일 vector budget에서 option crossing과 regret-to-oracle을 검사하도록 했다.
- FLARE·ViFailback·AgentChord·UPS를 strong baseline으로, SPR·FAR·CoRe·VLCP를 preprint novelty-collision set으로 분리했다.
- I-01, I-03, I-04, I-05, I-07, I-09, I-10은 최신 연구가 이미 닫은 broad claim을 제거하고 calibration, subgroup risk, compute matching, physical sensing cost, cross-morphology trade-off로 좁혔다.
- I-08을 multi-axis joint coverage audit로 유지하고, I-11은 morphology가 실제 worst-group bottleneck일 때만 시작하는 conditional backlog로 내렸다.
- 현재 첫 실행 단위는 LIBERO clone/restore validity와 20–50개 failure onset의 fixed-option sweep이다. option crossing이 관찰되지 않으면 learned selector novelty를 기각한다.
