## RP-2 priority sequence

`READING_PLAN.md`에 project-specific priority sequence를 추가했다. 전체 tier와 별개로 다음 다섯 단계로 구성한다.

1. `P0` Concept prerequisites: POMDP, DAgger, PPO/TRPO, Recovery RL, runtime failure prediction, CBF, human escalation, PDDLStream, long-horizon relay.
2. `P1` Direct detector/recovery baselines: FAIL-Detect, SAFE, FLARE, FaultEval, TD calibration, AHA, Counterfactual VLA, SafeVLA.
3. `P2` Benchmark/metric semantics: LIBERO, CALVIN, AtomicVLA, FurnitureBench, LIBERO-Safety, VLA-Arena, BEHAVIOR-1K, RLBench.
4. `P3` Frozen VLA/implementation branch: OpenVLA를 첫 pilot base로 두고 Octo, RT-1/RT-2, π0/π0.5, Decision Transformer, IQL/CQL, IBC, Q-Transformer를 필요에 따라 확장한다.
5. `P4` Optional extensions: long-horizon VLA, progress estimation, world-model uncertainty, memory, language replanning, demonstration augmentation과 data coverage.

15편 hard cap을 두지 않았으며, P0→P1→P2가 첫 실험의 필수 spine이다. P3/P4는 구현 선택과 후속 확장에 따라 읽는다.

## RP-2 methodology and experiment-spec hardening

`research/projects/RP-2_FAILURE_RECOVERY.md`와 I-02 summary를 다음 기준으로 동기화했다.

- frozen base policy와 lightweight alert/type/option-value head의 학습·라벨·추론 계약을 추가했다. cloned onset-state option sweep을 `q_o/r_o` target과 empirical upper bound의 단일 source로 정의했다.
- LIBERO-Long을 fit/calibration/confirmatory-test task split으로 분리하고, exact task·init-state·perturbation-seed 재사용을 금지했다. CALVIN은 LIBERO에서 재학습하지 않는 zero-shot transfer를 기본으로 고정했다.
- 비교군을 competence, detector/safety, recovery policy, proposed/oracle group으로 나누고, P1의 primary comparator를 development split에서 사전 고정한 strongest non-privileged `B*`로 정의했다.
- BRCR primary outcome, IFR one-sided non-inferiority gate, option regret, calibration, worst-group, latency와 paired cluster-bootstrap/Holm correction 규칙을 명시했다.
- A1–A8 ablation(typed cause, budget, heuristic routing, calibration, option-conditioned value, library, history, vector budget)과 interaction 조건, 5 pp/1 pp/3 pp reject margin을 추가했다.

이 변경은 논문 수나 tier를 바꾸지 않고 RP-2의 방법론·실험 설계만 구체화한 것이다. 실제 task manifest와 episode 수는 Phase 0 oracle audit 이후 `rp2_protocol_v1`로 고정한다.
