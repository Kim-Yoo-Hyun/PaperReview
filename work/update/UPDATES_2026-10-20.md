# 2026-10-20 — 기존 실험 종료와 새 VLA+RL 후보 검토

## 기존 작업에서 보존한 결과

로봇 간 RL 개선 전이와 동일 데이터 imitation 비교를 설계하고 실행 경로·기본 정책을 점검했다. Frozen-feature policy는 첫 Panda/milk qualification에서 초기 1/20, 마지막 chunk 비교 2/20에 그쳐 다음 연구 비교로 진행하지 못했다. Source RL과 target transfer는 미실행이며, 전이 가설이 반증된 것은 아니다. 수치의 조건과 제한은 [핵심 결과](../experiments/vla_rl_cross_embodiment/RESULTS.md)에 통합했다.

사용자 요청으로 이전 실험·지연 빌드업을 종료하고, 중복 문서·명세·실행 코드·환경 설정·상세 로그와 전용 실행 자원을 삭제했다. 일반 [빌드업 가이드](../../research/IDEA_BUILDUP_GUIDE.md), 논문 registry와 기존 정독 분석은 보존했다.

## 새 문헌 검토

- [후보 요약](../research_candidates/2026-10-20_vla_rl/README.md), [직접 충돌 문헌](../research_candidates/2026-10-20_vla_rl/LITERATURE.md), [가설·비교군·중단 기준](../research_candidates/2026-10-20_vla_rl/CANDIDATES.md)을 작성했다.
- 1순위는 **관측 비용과 실제 조작 결과에 따른 observe/execute 선택**, 2순위는 **수행 방식 지시의 조합 일반화**다. Active-perception RL이나 language-alignment RL 자체는 기존 연구로 인정한다.
- NeurIPS·CVPR·ICLR·ICML/PMLR·ACL 공식 proceedings로 확인한 status와 arXiv의 미확인 venue를 구분했다. AAWR·TVVE·SaPaVe·CounterAlign·how-level diagnosis 등의 본문/부록에서 확인한 범위와 공개 코드의 실제 확인 파일을 문헌 문서에 기록했다.
- 단순 규칙·고정 관측·동일 데이터 SFT·return-weighted imitation·표준 RL로 설명될 때 후보를 중단하거나 평가 연구로 축소하도록 했다.
- 일반 recovery/reset, memory expiry, prompt RL, continual forgetting, safety, latency를 넓은 신규 주제로 채택하지 않았다.
- 새 실험·패키지 설치·모델 다운로드는 수행하지 않았다. 신규성이나 현재 컴퓨터에서의 runtime 호환성이 입증된 후보는 없다.

## 남은 판단

두 후보의 gap은 확인한 선행 연구 범위에서의 조건부 질문이다. Native checkpoint/task의 기본 능력, 관측의 인과적 가치, 지시 쌍의 실행 가능성, 강한 baseline 대비 추가 이득을 검증하기 전에는 구현 프로젝트로 승격하지 않는다.

## 후속 요청 — 가능성이 높은 C1부터 진행

위의 “새 실험 없음 / 전용 Docker 자원 정리 완료”는 최초 후보 선별을 마친 시점의 기록이다. 이후 사용자가 우선 후보의 진행을 요청하여 **별도 C1 전제 확인 작업**을 시작했다. 이전 cross-embodiment 자원을 복원하지 않았다.

- [C1 후속 검토](../research_candidates/2026-10-20_vla_rl/C1_REVIEW.md), [진단 계약](../research_candidates/2026-10-20_vla_rl/C1_PROTOCOL.md), [source audit](../research_candidates/2026-10-20_vla_rl/C1_SOURCE_AUDIT.json)을 작성했다.
- ActiveAlign·EyeRobot 2.0·EgoReveal·PhysCaP의 관련 본문과 공개 interface를 확인했다. 모두 확인한 공식 venue가 없는 preprint로 구분했다. 추가 충돌로 넓은 C1 신규성은 약해졌으며, 고정 VLA에서 **추가 관측의 순이득이 양수인 상태만 선택 가능한가**로 질문을 좁혔다.
- SmolVLA의 최신-frame 입력, action queue, native state/action, image preprocessing, LIBERO init-state 증가 규칙을 소스에서 확인했다. Visual memory 가정, wrist 이동의 순수 정보 효과 주장, 동일 seed만으로 paired 비교라는 가정을 제거했다.
- G0 이후 base competence, 물리 primitive, 상태별 순이득, deployable observability, baseline 설명을 순서대로 검사하도록 했다. G1 이후는 아직 executable freeze가 아니며 learned selector·RL 학습을 시작하지 않았다.
- [Native probe](../experiments/vla_rl_active_handoff/README.md)는 고정한 공개 SmolVLA/LIBERO와 두 task, 최대 900초 rollout의 전제 확인이다. 패키지·모델·simulator assets는 전용 Docker image/volume으로 제한했다. Host에는 문서·자체 source·작은 결과만 둔다.
- Root/work/synthesis와 기존 후보 문서를 현재 판단에 맞춰 갱신했다. Registry admission·tier·사용자 reading/evidence는 변경하지 않았다.
- Host의 문서 유지보수 명령으로 generator compile·재생성을 실행했다. **CORE 47 / NEXT 246 / REFERENCE 439 / ARCHIVE 242** 유지 및 보호한 registry·notes·tier·tracker/history·synthesis 등 **4,884개 파일의 byte 보존**을 확인했다.
