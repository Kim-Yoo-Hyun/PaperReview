## Provenance and evidence boundary

공식 RSS proceedings, AAAI OJS proceedings/DOI record, IEEE record, IROS-linked project/repository, 저자·기관의 official project page와 arXiv abstract를 교차 확인했다. 신규 note의 `ABSTRACT_CHECKED`는 제목·연도·venue/status·problem/interface·공식 abstract에서 확인 가능한 evaluation scope만 확정한다.

- exact architecture detail, action horizon/control rate, trial count, split, failure case, ablation과 재현성은 `abstract 기반 — 본문 확인 필요`로 남겼다.
- HIL, SmolVLA, Gemini Robotics 1.5는 preprint status를 유지했다.
- GR00T N1.5/N1.6는 official NVIDIA technical report/system entry로 분류했으며 peer-reviewed proceedings로 세지 않았다.
- 기존 CORE/NEXT 논문의 사용자 status와 수동 synthesis 영역은 변경하지 않았다.

기존 `REFERENCE`의 3D-heavy 범위를 다시 점검했다. 판정은 `3D representation → robot state/world model → decision/control/feedback` 폐루프에 실제로 기여하는지로 나눴으며, PDF 보유 여부와 venue quota는 사용하지 않았다.

- **NEXT 승격 16편:** manipulation/action에는 UMPNet, Distilled Feature Fields, GaussianGrasper, ManiGaussian, Gaussian Splatting Visual MPC, POGS를, embodied 3D interaction에는 Act the Part와 Where2Explore를 배정했다. 3D perception/active exploration에는 Clio, HAMMER, VISTA, RoboRefer를, mobile manipulation에는 Language-Grounded Dynamic Scene Graphs와 DovSG를, planning에는 ST-OVSG를, VLA에는 From Spatial to Actions를 배정했다.
- **REFERENCE 유지:** [FastSLAM](https://www.cs.cmu.edu/~thrun/papers/montemerlo.fastslam-tr.html)과 [ORB-SLAM](https://arxiv.org/abs/1502.00956)은 robot pose·map posterior 및 tracking·mapping·relocalization·loop closing을 다루는 state-estimation foundation이지만, 이 audit에서는 사용자의 기준에 따라 `REFERENCE`를 유지했다.
- **ARCHIVE 이동 15편:** ReconFusion, Generative Gaussian Splatting, PartGen, G4Splat, HAD, WorldSplat, SuGaR, DeGauss, SplatFormer, LangSplat, CLIP-GS, Dr. Splat, SceneSplat, LightSplat, PhysSplat. 모두 registry에서 삭제하지 않고, 현재 확인된 contribution이 generic reconstruction/scene rendering/generation 또는 simulation에 머물며 robot state estimation, active perception, closed-loop behavior evaluation이 없는 항목으로 ID 기반 override를 추가했다.
- **REFERENCE 유지:** PTAM, KinectFusion, LSD-SLAM, ElasticFusion, GS-SLAM, Flash-Mono, depth/registration/equivariant representation, FROSS, EmbodiedOcc, FM-Fusion, LOCATE 3D, MR-COGraphs, M3 등은 직접 policy 성능을 보고하지 않더라도 state estimation·semantic mapping·online/embodied perception의 비교 기반으로 남겼다. 불확실한 항목을 제목만으로 추가 강등하지 않았다.
