## Clone 후 실행

[Portable Docker 경로](../experiments/portable/README.md)는 저장된 C3 logits의 지표 재분석만 지원한다. Python image digest·NumPy wheel hash·입력 hash를 고정하고 network-disabled/read-only 실행을 사용한다. 새로운 정책 학습·추론이나 GPU qualification을 수행하지 않는다. Native 후보의 HOLD/NO-GO/RETIRED를 해제하지 않았다.

기존 원격 저장소는 이번 uncommitted 파일을 포함하지 않는다. 다른 컴퓨터에서 사용하려면 변경 파일·raw evidence가 포함된 revision을 commit/push한 뒤 clone해야 한다. 실제 검증 범위와 결과는 [portable validation](../experiments/portable/VALIDATION.md)에 기록한다. Docker 동작은 [bind mount](https://docs.docker.com/engine/storage/bind-mounts/), [image pinning](https://docs.docker.com/build/building/best-practices/#pin-base-image-versions), [GPU support](https://docs.docker.com/desktop/features/gpu/) 공식 문서를 확인했다.
