## 1단계: User scope and decision

사용자가 지정한 주 연구 방향은 **VLA + RL 기반 manipulation·navigation**, 보조 축은 action-relevant 3D vision이다. 기존 registry 950편의 우선순위와 읽기 흐름을 갱신했다. 논문 신규 등록·삭제·폴더 이동은 없으며 7개 primary track은 유지한다.

오래된 연도 자체를 강등 사유로 사용하지 않았다. TD·policy gradient·PPO·SAC·POMDP·impedance처럼 현재 학습 objective와 control interface의 prerequisite는 CORE에 유지한다. Pure gait/whole-body tracking, 특수 tactile hardware, 일반 reconstruction은 실제 구현 요구에 따라 조회하도록 옮긴다. CORE의 모든 항목에 목표 연구와의 dependency 이유를 생성 source와 reading plan에 기록했다.

## Research flow

- VLA+RL manipulation: SAC/IQL/CQL → RLPD/SERL/HIL-SERL; OpenVLA/OFT → ConRFT의 direct fine-tuning과 RLDG의 RL-data distillation 비교.
- Navigation: Habitat/VLN-CE → ViNT/NoMaD, ConceptFusion/VLFM → SayCan/NaVILA; FeedTTA·Habitat 2.0를 NEXT에 포함.
- 3D: RVT·DP3·semantic mapping처럼 policy/action으로 이어지는 비교를 우선한다. 3DGS·DUSt3R의 일반 재구성 원전은 REFERENCE.
- CORE 전체 완독을 NEXT 진입 조건으로 두던 규칙을 해당 branch prerequisite를 확인한 뒤 병행하는 규칙으로 바꿨다. 읽기 순서의 canonical source는 계속 [READING_PLAN.md](../../research/READING_PLAN.md) 하나다.
- Habitat의 비어 있던 primary track을 `RL, IL, offline learning, and robot data`로 배정했다. Task/simulator benchmark라는 contribution에 따른 배정이며 새로운 navigation taxonomy를 만들지 않았다.

## Evidence boundary and official sources

재검토 범위는 공식 proceedings/abstract/project/code 설명과 기존 registry 및 note다. Source check는 curation 근거이며 reading status나 full-text evidence를 새로 올린 것이 아니다. 출판 metadata는 이번 변경에서 다시 쓰지 않았다.

- RSS 2025 공식 proceedings에서 [ConRFT](https://www.roboticsproceedings.org/rss21/p019.html), [RLDG](https://www.roboticsproceedings.org/rss21/p028.html), [OpenVLA-OFT](https://www.roboticsproceedings.org/rss21/p017.html), [NaVILA](https://www.roboticsproceedings.org/rss21/p018.html), [FAST](https://www.roboticsproceedings.org/rss21/p012.html)의 publication 및 abstract contribution을 확인했다.
- [RLPD / ICML 2023](https://proceedings.mlr.press/v202/ball23a.html), [FeedTTA / ICML 2025](https://proceedings.mlr.press/v267/kim25ad.html), [ViNT / CoRL 2023](https://proceedings.mlr.press/v229/shah23a.html), [DP3 / RSS 2024](https://www.roboticsproceedings.org/rss20/p067.html)로 policy improvement/navigation/3D 역할을 확인했다.
- [Habitat / ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/html/Savva_Habitat_A_Platform_for_Embodied_AI_Research_ICCV_2019_paper.html), [VLN-CE / ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/html/6018_ECCV_2020_paper.php), [R2R / CVPR 2018](https://openaccess.thecvf.com/content_cvpr_2018/html/Anderson_Vision-and-Language_Navigation_Interpreting_CVPR_2018_paper.html), [Habitat 2.0 / NeurIPS 2021](https://proceedings.neurips.cc/paper_files/paper/2021/hash/021bbc7ee20b71134d53e20206bd6feb-Abstract.html)에서 navigation task/evaluation과 rearrangement 연결을 확인했다.

- ReinboT의 기존 OpenReview 페이지는 접근 검증 화면이 반환되어 이번 승격 대상으로 삼지 않았다. FeedTTA는 PMLR 공식 페이지로 재확인했다.

### 판단

현재 registry에는 OpenVLA/OFT/π0, ConRFT/RLDG/HIL-SERL, NaVILA/Uni-NaVid, Ctrl-World/WMPO/WorldGym 등이 이미 있다. 가장 큰 빈틈은 **생성형 action policy를 RL로 개선하는 방법과 그 평가 기준**, 그리고 **2026년의 world-model 기반 개선·navigation 배포 연구**다. 오래된 foundation을 더 줄이는 것만으로 이 빈틈이 채워지지는 않는다.

구분해야 할 흐름은 다음과 같다.

1. Diffusion/flow 정책의 직접 RL, Q-learning, frozen-policy latent steering은 서로 다른 개선 방식이다. DPPO·FQL·DSRL을 비교하면 ConRFT/RLDG 이후의 설계 선택을 구체화할 수 있다.
2. Action chunk의 길이는 exploration·value backup뿐 아니라 반응성에도 영향을 준다. Q-chunking과 DQC는 ACT/FAST의 action 표현을 RL 학습 문제와 연결한다.
3. World model의 영상 품질, imagined rollout을 통한 policy improvement, 실제 robot에서의 improvement는 별도 검증 대상이다. VLAW·VLA-MBPO·RISE를 우선 비교하고 PersistWorld는 해당 모델의 fidelity 연구로 참조한다.
4. Navigation에서는 video memory, local trajectory generation, metric geometry, socially compliant reward를 분리해 비교한다. 이 관점에서 NaVid·StreamVLN·NavDP·LoGoPlanner·SocialNav의 역할이 다르다.
5. Benchmark는 success만으로 충분하지 않다. OGBench는 장기 goal-conditioned 학습 능력, RL4VLA는 일반화 축, OopsieVerse는 damage를 비교하는 기준을 보충한다.

## 6–7단계: 종료한 빌드업의 핵심 판단

2026-10-19에는 VLA 실행 지연과 다양한 로봇을 위한 VLA+RL을 검토했다. 지연 대응은 RTC·AAC·REMAC·TIC-VLA 등과 직접 겹쳐 넓은 방법 기여로 채택하지 않았다. 로봇 간 RL 전이는 동일 source data의 imitation 비교를 포함하는 검증 질문으로 좁혔으며, 당시에는 설계 단계였다.

2026-10-20 후속 점검에서는 기본 학습 정책의 qualification 미달로 주 전이 비교에 도달하지 못했다. 사용자 요청에 따라 이전 작업의 상세 문서와 실행 자원을 정리하고 [질문·핵심 결과·교훈](../experiments/vla_rl_cross_embodiment/RESULTS.md)으로 통합했다. 이는 전이 가설의 반증을 뜻하지 않는다.

위 1–5단계의 registry·문서 정비 이력은 그대로 보존한다. 현재 후보와 변경 후 검증은 [2026-10-20 기록](./UPDATES_2026-10-20.md)을 따른다.
