## 무엇을 보강했는가

1. **VLA 내부 학습과 보상 대상.** SRPO·EvoVLA·RehearseVLA·LongNav-R1·MobileVLA-R1·VLA-R1을 통해 환경 상호작용, 학습 보상, 중간 trajectory/region의 검증 보상을 구분한다. VLA-R1의 affordance/trajectory 출력과 downstream control은 직접 joint-action RL과 다르다. [CVPR SRPO](https://openaccess.thecvf.com/content/CVPR2026/html/Fei_SRPO_Self-Referential_Policy_Optimization_for_Vision-Language-Action_Models_CVPR_2026_paper.html), [EvoVLA 공식 chapter](https://link.springer.com/chapter/10.1007/978-3-032-37023-5_14), [VLA-R1 저자 설명](https://gigaai-research.github.io/VLA-R1/).
2. **실패·보상·가치 학습의 직접 대조.** ReWiND, Dopamine-Reward/RL, PRIMT, DEAS, Q2RL을 추가했다. HINDSIGHT의 실패 활용과 UNIFIED의 critic 학습을 검토할 비교 후보이며, 초록만으로 기존 후보를 반증하거나 새 방법의 독립성을 확정하지 않는다. [ReWiND](https://proceedings.mlr.press/v305/zhang25a.html), [General Process Reward Modeling](https://openaccess.thecvf.com/content/CVPR2026/html/Tan_General_Process_Reward_Modeling_for_Robotic_Reinforcement_Learning_CVPR_2026_paper.html), [DEAS](https://proceedings.iclr.cc/paper_files/paper/2026/hash/68b7f71467c83d5d32275c5acbf6b588-Abstract-Conference.html).
3. **RL 정책 갱신과 경쟁하는 간단한 대안.** V-GPS·CoVer·VERITAS는 value/verifier로 추론 행동을 고르는 대안이고, TMRL·CE-Nav는 명시적인 상위 조절·refiner 경계가 있다. MM-ACT·LDA-1B의 통합 생성/표현 자체는 이미 통합 RL objective의 효과를 입증한 것이 아니다. [V-GPS](https://proceedings.mlr.press/v270/nakamoto25a.html), [CoVer](https://arxiv.org/abs/2602.12281), [TMRL](https://weirdlabuw.github.io/tmrl/).
4. **실패를 구별하는 평가.** PolaRiS·MolmoSpaces·KinDER·MoMa-Kitchen과 Contrast Sets·ICBench를 등록했다. 단순 평균 성공뿐 아니라 지시 모순, 물리 reasoning, mobile base의 manipulation 가능성까지 비교할 자원이다. 각 benchmark의 평가 권한·split·control 조건은 본문에서 별도로 확인해야 한다. [KinDER](https://roboticsproceedings.org/rss22/p184.html), [Contrast Sets](https://proceedings.mlr.press/v270/anwar25a.html), [ICBench/IGAR](https://link.springer.com/chapter/10.1007/978-3-032-37152-2_3).
5. **항법·접촉·행동 관련 3D.** LiReN, GRAD-NAV++, Force Policy, OmniReset, RoTO, PEAfowl, PROSPECT를 포함했다. Reset coverage·tactile representation·multi-view geometry가 RL 개선처럼 보이는 confound인지 확인할 연결이다. [LiReN](https://proceedings.mlr.press/v270/stachowicz25a.html), [GRAD-NAV++](https://ieeexplore.ieee.org/document/11297793/), [Force Policy](https://roboticsproceedings.org/rss22/p128.html).

위 연결은 **CURATION-HYPOTHESIS**다. 기존 후보의 실행 계약·NO-GO/HOLD를 바꾸지 않았고 새 연구 후보를 문헌 수만으로 승격하지 않았다. HINDSIGHT/UNIFIED의 학습 비교나 신규성 주장 전에 가까운 새 선행의 본문·코드·baseline fairness 대조가 필요하다.

## 조사 범위와 중복·버전 판단

RSS 2025/2026, CoRL 2024/2025, CVPR 2026, ICCV 2025는 공식 title index에서 robotics/learning/evaluation 관련 후보를 발견하고 기존 registry와 대조했다. ICLR 2026·NeurIPS 2025·ECCV 2026·RA-L은 paper-specific source와 accepted list/publisher를 추가 대조했다. Index 추출 수는 본문 검토 수가 아니다. 2024–2026 전체 venue의 모든 논문을 전수 읽었다고 주장하지 않는다.

- Exact/normalized title과 DOI/arXiv/OpenReview 식별자로 중복을 점검했다. 기존 SimpleVLA-RL·Robometer·ForceVLA2·ACoT-VLA·ActiveVLA 등의 항목은 다시 등록하지 않았다.
- WPT는 자율주행 중심의 world-model distillation으로, 이번 조작·항법 registry 보완의 직접성이 낮아 제외했다. ICRA/IROS 및 NeurIPS 2026 발견 결과도 main-track status와 신규 가치를 확인한 항목만 admission할 원칙을 유지했다. 이번 추가 수를 venue별로 맞추지 않았다.
- CoRL 2024는 PMLR 270의 출판 연도 2025와 event year 2024를 구분했다. GRAD-NAV++는 2025-12 online / RA-L 2026 issue다. PEAfowl은 RA-L 11(10), PROSPECT는 11(11)의 2026 issue metadata로 확인했다.
- GRAD-NAV++는 기등록 GRaD-Nav(pr-0290)의 언어 조건부 확장으로 별도 보존하고 extends 관계를 명시했다. JALA·BPP·Robo-Dopamine·MolmoSpaces 등의 preprint 제목은 alias로 저장했다.
- MobileVLA-R1 2.0과 FP2를 원 논문의 추가 실험으로 합치지 않았다. FlashSAC·KinDER의 최신 preprint와 proceedings 사이의 평가 규모 차이도 overview에 남겼다.
- JALA의 README/docs 공개를 구현 공개로 표시하지 않았다. DIPOLE은 repository 존재와 전체 training 구현 확인을 구분했다. 공개 code URL·파일 존재는 실행 재현 성공을 뜻하지 않는다.
- IEEE의 일부 HTML 접근 제한은 publisher 검색 결과·Crossref DOI metadata·저자 arXiv로 보완했다. 원문 전체 확인으로 표시하지 않았다.
